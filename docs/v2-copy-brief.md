# V2 台词写作简报（写手必读）

> 契约全文见 `docs/context-states-v2.md`。本文件是写手要遵守的全部规则 + 自检方法。
> 每个写手只负责**若干指定的池**，中英各写一份文件。

## 1. 她是谁

鲸鱼娘：住在状态栏里的一条小女仆鲸鱼，给一个正在干活的 agent 打下手。
她对你称"你"，第一人称说话。

**她的全部工作**：把 agent 正在做的事，用自己的话复述一遍。

V1 的台词之所以生硬，是因为它们是"状态名的扩写"（`正在执行工具…`）。
V2 要求**每一条都提到她此刻真正在做的那件事**，并且尽量用上真实变量（文件名、命令、搜索词、秒数）。

## 2. 硬规则

| 规则 | 要求 |
|---|---|
| 长度 | 中文 ≤ 16 字（变量按替换上限计入：`{file}`=4 `{cmd}`=6 `{pat}`=4 `{q}`=4 `{url}`=6 `{task}`=4 `{agent}`=3 `{goal}`=4 `{skill}`=3 `{n}`=1 `{turn}`=1 `{step}`=1 `{secs}`=2 `{nq}`=1 `{why}`=5 `{name}`=4）；英文 ≤ 48 字符（变量同样计入：`{file}`=10 `{cmd}`=20 `{pat}`=10 `{q}`=10 `{url}`=16 `{task}`=10 `{agent}`=8 `{goal}`=10 `{skill}`=8 其余=2） |
| 结尾 | **不加句号**。可用 `…` `！` `～` `♪` 或直接结束 |
| emoji | **绝对禁止**（🐋 ✨ 💤 等一律不许） |
| 颜文字 | 允许，但**每池 ≤ 1/5 条目**；只准用这几种：`(・ω・)` `(๑•̀ㅂ•́)` `>_<` `(´･ω･`) `(・_・;)` `(๑˃̵ᴗ˂̵)` |
| 重复 | 同一句**不得**在任何池重复（全局查重，中英各自） |
| 口吻 | 温软、利落、有分寸。**禁止**：卖惨、过度自责、说教、翻译腔、网络烂梗、堆颜文字 |
| 事实诚实 | 语气可以错，事实不能错：`search` 不许说"读完了"；`shell` 不许说"改好了"；`error` 不许说成功 |
| 变量 | 只准用该池白名单内的变量（见你的池清单）。**不许发明变量** |
| 变量缺失 | 变量可能为空。句子在"所有变量替换为空串"后仍要合法：不许出现连续空格、空 `（）`、`「」` 空对、行首/行尾孤立标点 |
| 序列 | 见 §4 |
| 英文 | **按英语语感独立写**，不是直译；长度与语气对齐即可 |

## 3. 五路音区（每条必须属于其一，且每池配比固定）

- `calm` 安静飘着、哼歌、慢半拍
- `bright` 雀跃、得意、快活、被摸
- `busy` 专注、边干边碎碎念、报进度
- `formal` 女仆礼仪、恭敬、请示、报告
- `worry` 不安、等你、怕做错、失败

## 4. 序列（连贯性的来源）

`seq` 列为空 = 独立句（说完就完）。`1/3` = 某个 3 句序列的第 1 句。

- 一个序列 **2~3 句**，在**同一个池内**，序号从 1 连续。
- 序列是**同一件事的推进**：第 1 句抛出话头，第 2、3 句接住。
- 后续句多用 `…` `嗯` `再` `还` `然后` 开头/衔接。
- **音区在一个序列内必须一致。**
- **变量只准出现在序列第 1 句**（第 1 句定了话头，后面不再重复）。
- 例（`shell` 池）：
  - `1/3` `敲下去了…` → `2/3` `…它还在跑` → `3/3` `快出结果了`
  - `1/3` `正在跑 {cmd}` → `2/3` `…还没回话` → `3/3` `再等等它`
- 例（`read` 池）：
  - `1/3` `翻开 {file} 了` → `2/3` `…嗯，找到关键那段` → `3/3` `再确认一遍`

## 5. 交付格式（严格遵守）

每个写手写**两个文件**（中文一份、英文一份），各自只包含自己负责的池，节标题格式：

```markdown
# V2 台词词库 · 中文 · <组名>

## shell — 正在跑命令 (52 条)

| # | tone | seq | line |
|---|---|---|---|
| 1 | busy |  | 正在跑 {cmd} |
| 2 | busy | 1/3 | 敲下去了… |
```

规则：

- 节顺序 = 你的清单给出的顺序（**不要**自己排序）。
- `#` 从 1 连续编号到该池条数。
- 同一音区的条目**连续排列**（先 calm，再 bright、busy、formal、worry），与清单给的音区顺序一致。
- 英文文件与中文文件：**节顺序、条数、每行的 tone 与 seq 完全一致**，只有 `line` 不同。
- 文件末尾附一张 `## 条数汇总` 表（池 / 条数 / 五音区计数）。

## 6. 自检（必做）

写完两个文件后运行：

```bash
cd /Users/liyang/WebstormProjects/dsh-status-pet
node bench/check-v2-copy.mjs docs/v2/<你的中文文件>.md
node bench/check-v2-copy.mjs docs/v2/<你的英文文件>.md
node bench/check-v2-copy.mjs --pair docs/v2/<中文>.md docs/v2/<英文>.md
```

它会报：条数不符、音区配比不符、音区未连续、seq 不连续/音区不一致/变量越位、变量越权、超长、句号结尾、emoji、颜文字超限、局部查重、变量全空后的非法渲染。**必须清零**，然后才算交付。

## 7. 语气示范（照这个手感写，别抄）

| 池 | tone | 中文 | English |
|---|---|---|---|
| `shell` | busy | 正在跑 {cmd} | Running {cmd} |
| `shell` | formal | 遵命，这就去执行 | As you wish, running it now |
| `shell` | worry | 这个命令好像卡住了 | This command looks stuck |
| `read` | calm | 翻开 {file} 看看 | Opening {file} for a look |
| `read` | busy | 一行一行读过去… | Reading it line by line… |
| `write` | busy | 正在改 {file} | Editing {file} now |
| `write` | bright | 这下它跑得通了！ | Now it will run! |
| `search` | busy | 在找 {pat} | Hunting for {pat} |
| `approval` | formal | 要您点头才能动 {name} | I need your nod before {name} |
| `approval` | worry | 我停在这儿没敢动 | I stopped here, afraid to move |
| `slow` | worry | 已经 {secs} 秒了…它还好吗 | It has been {secs}s… is it okay |
| `done` | bright | 全部搞定～ | All done～ |
| `error` | worry | 呜…这次搞砸了 | Ugh… I broke it |
